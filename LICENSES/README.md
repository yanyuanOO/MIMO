# Licensing Notes

Do not add a single broad dataset license until the source-by-source audit is complete.

The recommended release model is:

1. A software license for code.
2. A clear license or research-use agreement for original MIMOSeg annotations and metadata.
3. Preservation of every upstream dataset’s license, notices, and restrictions.
4. No redistribution of source images where permission is absent or unclear.

`SOURCE_LICENSE_MATRIX.csv` is a working audit document. Every `REVIEW_REQUIRED` cell must be resolved before launch.
